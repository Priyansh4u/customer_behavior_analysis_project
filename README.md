# 📊 Data Analytics Project -- End-to-End Business Analysis

## 🔎 Overview

This project demonstrates a complete data analytics workflow from raw
dataset to business insights and presentation. The goal was to analyze
transactional data, uncover trends and patterns, and deliver actionable
insights using Python, SQL, and Power BI.

The project includes data loading, exploratory data analysis (EDA), data
cleaning, SQL-based analysis in PostgreSQL, dashboard creation, report
writing, and presentation development.

------------------------------------------------------------------------

## 📁 Dataset

The dataset contains transactional and customer-related information such
as:\
- Customer demographics\
- Product and category details\
- Purchase amounts and discounts\
- Behavioral attributes

The data was used to analyze revenue trends, customer segments, and
product performance.

------------------------------------------------------------------------

## 🛠 Tools & Technologies

-   Python (Pandas, NumPy, Matplotlib/Seaborn) -- Data loading,
    cleaning, and EDA\
-   PostgreSQL (SQL) -- Business queries and structured analysis\
-   Power BI -- Interactive dashboard development\
-   Microsoft PowerPoint -- Final presentation of insights

------------------------------------------------------------------------

## ⚙️ Project Workflow

### 1️⃣ Data Loading (Python)

-   Imported dataset using Pandas\
-   Checked data types, structure, and summary statistics

### 2️⃣ Exploratory Data Analysis (EDA)

-   Analyzed distributions and key metrics\
-   Identified trends and patterns\
-   Checked for missing values and anomalies

### 3️⃣ Data Cleaning & Transformation

-   Handled missing values\
-   Standardized column names\
-   Performed feature engineering\
-   Ensured data consistency

### 4️⃣ SQL Analysis (PostgreSQL)

-   Loaded cleaned dataset into PostgreSQL\
-   Executed SQL queries to answer business questions\
-   Performed revenue, segmentation, and performance analysis

### 5️⃣ Dashboard Development (Power BI)

-   Built interactive visualizations\
-   Created KPIs and summary metrics\
-   Enabled filtering and drill-down insights

### 6️⃣ Reporting & Presentation

-   Documented findings in a structured report\
-   Created a professional PowerPoint summarizing key insights and
    recommendations

------------------------------------------------------------------------

## ▶️ How to Run

1.  Clone the repository\
2.  Install required Python libraries:\
    pip install pandas numpy matplotlib seaborn psycopg2\
3.  Run the Python script or Jupyter Notebook for EDA and cleaning\
4.  Load the cleaned dataset into PostgreSQL\
5.  Execute SQL queries for analysis\
6.  Open the Power BI file (.pbix) to view the dashboard\
7.  Review the final report and presentation for summarized insights
